# Migración del SDK de medios independiente a Adobe Launch

>[!NOTE]
>Adobe Experience Platform Launch se ha convertido en un conjunto de tecnologías de recopilación de datos en Experience Platform. Como resultado, se han implementado varios cambios terminológicos en la documentación del producto. Consulte el siguiente [documento](https://experienceleague.adobe.com/docs/experience-platform/tags/term-updates.html?lang=es) para obtener una referencia consolidada de los cambios terminológicos.

Esta documentación se centra principalmente en las diferencias de implementación de Media Analytics
entre Media SDK independiente y la extensión de Launch de Media Analytics.

Launch ofrece una alternativa sencilla para implementar y gestionar todos los análisis,
soluciones de marketing y publicidad necesarias para potenciar a los clientes relevantes.
experiencias en la web y dispositivos móviles. Launch ofrece a los usuarios las herramientas necesarias para generar y mantener
sus propias integraciones con Launch. Estas integraciones se denominan extensiones.
Los clientes de Launch encontrarán las extensiones disponibles en las tiendas de aplicaciones para que
puede instalar, configurar e implementar rápidamente sus soluciones.

Adobe Media Analytics para audio y vídeo está disponible como una extensión de Launch tanto para la web como para dispositivos móviles:

* [Documentación de Web Launch](https://experienceleague.adobe.com/docs/experience-platform/tags/extensions/adobe/media-analytics/overview.html?lang=es)
* [Documentación de Mobile Launch](https://developer.adobe.com/client-sdks/documentation/adobe-media-analytics/)
